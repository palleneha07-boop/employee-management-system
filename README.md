# Employee Management System

A simple **Employee Management System** developed using Java that helps manage employee records efficiently. The application allows users to add, view, search, update, and delete employee information through a console-based interface.

## Features

* Add new employee records
* View all employee details
* Search employees by ID
* Update employee information
* Delete employee records
* Store employee details using ArrayList
* Simple menu-driven interface

## Technologies Used

* Java
* ArrayList (Java Collections Framework)
* Scanner Class
* Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/employee-management-system.git
```

2. Navigate to the project directory:

```bash
cd employee-management-system
```

3. Compile the Java file:

```bash
javac EmployeeManagementSystem.java
```

4. Run the application:

```bash
java EmployeeManagementSystem
```
